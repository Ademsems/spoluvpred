# Spolu Vpred — website

Bilingual (Slovak / English) website for the civic association **OZ Spolu Vpred** — interactive workshops and prevention activities for primary and secondary schools.

Next.js 14 (App Router) · TypeScript strict · Tailwind CSS · Framer Motion · Lucide.

```bash
npm ci
npm run dev      # http://localhost:3000
npm run build
npm run lint
```

Copy `.env.example` to `.env.local` to enable e‑mail delivery of the contact form.

**Full documentation — architecture, design tokens, i18n conventions, form rules, donation data and the list of items still waiting on the client — is in [CLAUDE.md](./CLAUDE.md).**
